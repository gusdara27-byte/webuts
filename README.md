## Halaman
1. `index.html` — Beranda
2. `tentang.html` — Tentang usaha, visi-misi, dan tim
3. `katalog.html` — Enam contoh produk bakery
4. `kontak.html` — Informasi kontak, tabel jam operasional, dan formulir

## Fitur
- Navigasi yang menghubungkan empat halaman.
- HTML semantik: header, nav, main, section, article, dan footer.
- Katalog menggunakan CSS Grid.
- Navigasi menggunakan Flexbox.
- Tampilan responsif untuk layar HP dan desktop.
- Efek hover, transition, dan keyframes.
- Formulir dengan validasi bawaan HTML5.
- Tabel jam operasional.

## Cara menjalankan
Buka file `index.html` menggunakan browser. Pastikan koneksi internet tersedia agar foto dari Unsplash dapat ditampilkan.

## Sumber gambar
Foto menggunakan tautan gambar dari Unsplash:
- https://unsplash.com/
Tautan foto spesifik tercantum langsung pada atribut `src` dan CSS.


## JavaScript dan backend
JavaScript tidak digunakan karena fitur JavaScript pada soal bersifat opsional. PHP dan database juga tidak digunakan. Formulir memakai validasi HTML5 di browser, tetapi belum mengirim pesan ke server karena proyek ini merupakan website statis.
